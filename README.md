# Mantelet

Reader: a parent, a teacher, or anyone new to this project. You do not need to know anything technical.

Last reviewed: 8 October 2026

## What this is

Mantelet is a research project. It asks one question:

> Can we make it much harder to turn an ordinary photo of a woman or a child into a fake sexual or nude image?

We do not know the answer yet.

## Warning: Mantelet does not protect anyone yet

Today there is no tool to download or use. Nothing here can protect your photos. Please do not rely on it.

Even if we build a tool later, a photo that has been through it can still be misused. One unprotected photo of the same person can defeat it. Earlier research suggests that hidden changes to a photo often stop working once someone attacks them on purpose. We will test this honestly. We will publish the result, even if the answer is no.

## What we are doing

We work on two things at the same time:

1. **Research.** We test whether hidden changes to a photo can make fake images harder to make. We report what we measured and what we could not measure.
2. **Guides for families and communities.** We write clear steps for what people can do today. These cover how to get images taken down and how to report them. They do not depend on the research working.

The project is also a learning project. The owner is learning Python and machine learning while building it. Everything is open source from the first day.

## Safety rules

The hard rules are in [SAFETY.md](SAFETY.md). The short version: this project never makes sexual or nude images of anyone. It never uses images of children. It never uses real people without written consent.

## The name

A mantelet is a short cloak. It is also a portable shield. The name says what we hope to build, and does not claim we have built it.
