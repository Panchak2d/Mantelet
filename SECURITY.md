# Security policy

Reader: anyone who found a security problem in this project's code or repository settings.

Last reviewed: 5 October 2026

## What counts as a security problem

A flaw in the code, the build files, or the repository settings that could let someone do harm. Examples are a leaked key, a file that runs unsafe code, or a dependency with a known weakness.

## How to report it

Please do not open a public issue.

1. **Preferred:** use the private report form: [Report a vulnerability](https://github.com/Panchak2d/mantelet/security/advisories/new). Only the maintainer can see it. The maintainer turns this form on in the repository settings. If the page does not let you submit a report, use option 2.
2. **Email:** nothingblank37@gmail.com

Please include what you found, how to repeat it, and what you think the harm could be. Do not attach images of people.

## What to expect

This is a volunteer project run by one person. We aim to reply within 7 days, but it may take longer. We will tell you what we decide. If you want credit for the report, tell us how you would like to be named.

## Supported versions

There are no releases yet. Only the latest code on the main branch is supported.

## What this page does not cover

- **Abusive material involving a child.** Do not send it to us. Follow rule 6 in [SAFETY.md](SAFETY.md).
- **Conduct problems.** See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Weaknesses in the research ideas.** If you think a protection idea does not work, that is welcome as a public issue. It is research feedback.
